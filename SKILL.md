# Project lifecycle

Read [WORKFLOW.md](WORKFLOW.md) before working. It is the single, tool-neutral instruction for this method. Project-specific facts live only in the project's local context.

For an empty workspace, read [start-project.md](references/start-project.md). For installation in another environment, read [portability.md](references/portability.md). For a designed report, read [report-style.md](references/report-style.md). Use only the references relevant to the request.

The core workflow is independent of a particular model or tool. Optional project instruction files for agents that support them are short pointers to the same workflow; they are not required to start a project.
