# Optional icons

All SVGs use the same narrow line style and report palette. Use an icon only when it clarifies the content. Do not treat icon names as a fixed project taxonomy.

| Situation | Examples |
|---|---|
| Confirmed outcome | `confirmed`, `milestone`, `decision-made` |
| Investigation and validation | `research`, `cross-check`, `estimate`, `hypothesis` |
| Waiting or missing information | `wait-dependency`, `external-wait`, `task-no-data`, `needs-decision` |
| Problem or rework | `risk`, `blocker`, `rework-loop`, `return-broken` |
| Work in progress | `prototype`, `queue`, `expectations` |

Other SVGs in the folder are available for closer matches. Keep icon choice and any color meaning consistent within one report.
