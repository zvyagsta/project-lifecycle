# intake-material — receive an incoming material

**When:** a recording, transcript, document, table or message arrives from people.

**Input:** the file, its source role and receipt date.

**Steps**
1. Store the original once in the incoming folder of the workstream it belongs to, in a dated subfolder. Do not edit it.
2. Record in the context: source role, receipt date, review status (received, reviewed, linked to finding) and the path.
3. Other workstreams link to the same file instead of copying it.

**Result:** one canonical original and a context entry.

**Done when:** the material is findable from the context and its review status is stated.

**Do not:** treat receipt as review, or a review as agreement. Rules: [lifecycle.md](../references/lifecycle.md).
