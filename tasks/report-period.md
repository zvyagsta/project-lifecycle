# report-period — report and infographic for other readers

**When:** a report for a manager or a team: «отчёт за день», «инфографика».

**Input:** the approved facts of the period; the project's text rules and approval gate.

**Steps**
1. Draft the text from evidence; keep sources in the internal version only.
2. Stop for the user's approval of the draft text.
3. After approval, fill `assets/report-style/report.html` and `infographic.html` (or the project's copy of them) and render them at the intended size.
4. Check the final layout and text; keep the previous set in the archive.

**Result:** the approved report files; delivery is a separate step.

**Done when:** the user approved the text and the rendered files match it.

**Do not:** send or publish without separate authorization; shrink type to fit — shorten the text with approval. Details — [report-style.md](../references/report-style.md).
