# update-context — record a substantive iteration

**When:** a result file appeared or changed, a decision was made, a meeting took place, a material arrived, a question was closed or opened, or a day ends.

**Input:** what changed, why, what remains open, the next step.

**Steps**
1. Add a dated entry to the active workstream context; update the project overview only when the whole project changes.
2. Link new results; point current navigation to the new version and keep the old one in the archive.
3. Run the project's link check and fix broken links.
4. In the reply, name the context sections that were updated.

**Result:** a context that a new reader can continue from.

**Done when:** the link check passes or the remaining failures are reported.

**Do not:** rewrite historical facts to match the current plan; record a proposal as a decision.
