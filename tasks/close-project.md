# close-project — close the whole project

**When:** the user asks to close the project.

**Input:** all workstream closures, project-level acceptance, delivery or handover, support owner, open obligations.

**Steps**
1. Check that every workstream is closed or explicitly handed over.
2. Record project-level acceptance, delivery, the support or maintenance owner, open obligations, archive locations, and an entry point for a future reader.
3. If any item is unconfirmed, describe the project as awaiting closure.

**Result:** a closure record in the project overview.

**Done when:** a future contributor can find the final results and who owns what.

**Do not:** close the project while acceptance or ownership is unconfirmed. Rules: [lifecycle.md](../references/lifecycle.md).
